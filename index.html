PLEASE NOTE THE RULES OF THE SERVER

⚖️ قوانين عامة
• احترام الجميع وعدم السب أو العنصرية.

• Meta Gaming: يمنع استخدام معلومات خارجية.
• الهدف هو المتعة والواقعية.
👮 قوانين الشرطة
• احترام المواطنين والتعامل الرسمي.
• إعطاء تحذير قبل إطلاق النار.
• الالتزام بالأوامر والرتب العسكرية.
• استخدام التيزر عند الحاجة فقط.
⚔️ قوانين العصابات
• سبب قوي لأي هجوم أو خطف.
• ممنوع قتل الرهائن بدون سبب.
• الالتزام بلون العصابة الرسمي.
🚑 قوانين الإسعاف
• علاج الجميع بدون تمييز.
• الالتزام بالواقعية الطبية.
• الاستجابة السريعة للبلاغات.
🏛️ قوانين العدل
• احترام القاضي والجلسة.
• وجود أدلة قبل الحكم.
• المحامي له حق الدفاع الكامل.
🛠️ قوانين الميكانيكي
• تصليح السيارات بشكل واقعي.
• الالتزام بأسعار السيرفر.
