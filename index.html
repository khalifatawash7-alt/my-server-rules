القوانين

PLEASE NOTE THE RULES OF THE SERVER

⚖️ قوانين عامة
• احترام الجميع وعدم السب أو العنصرية.
• الالتزام بالشخصية داخل الرول بلاي.
• الخوف على الحياة (Fear RP) وقت التهديد أو الخطر.
• ممنوع استخدام معلومات خارج اللعبة داخل اللعبة (Meta Gaming).
• ممنوع التصرف بشكل غير واقعي أو خارق (Power Gaming).
• ممنوع القتل أو السرقة بدون سبب RP واضح.
• ممنوع الخروج من السيرفر وقت السيناريو.
• احترام القوانين والإدارة واللاعبين.
• الهدف هو المتعة والواقعية مو الفوز.
• ممنوع استغلال البقزات أو الغش.
👮 قوانين الشرطة
• احترام المواطنين والتعامل الرسمي.
• استخدام السلاح يكون عند الضرورة فقط.
• إعطاء تحذير قبل إطلاق النار.
• الالتزام بالأوامر والرتب العسكرية.
• الحفاظ على أمن المدينة والنظام العام.
• يمنع منعاً باتاً استخدام السلاح بشكل عشوائي.
• إذا معك سلاح أبيض يتم التعامل بحذر وتحذير أولاً.
• إذا معك سلاح ناري يتم التعامل فوراً حسب التهديد.
• إذا تم توجيه السلاح عليك يُسمح باستخدام الصلاحيات حسب الحالة.
• إطلاق النار على العجلات لإيقاف المركبة.
• النطح + تقييد المشتبه (كلبشة).
• استخدام التيزر ضد الشخص أو السيارة عند الحاجة.
⚔️ قوانين العصابات
• لازم سبب قوي لأي هجوم أو خطف.
• ممنوع قتل الرهائن بدون سبب RP.
• احترام التحالفات والعداوات.
• الالتزام بالواقعية في العمليات.
• ممنوع الهجوم العشوائي.
• الالتزام بعدد أفراد حسب قوانين السيرفر.
🚑 قوانين الإسعاف / الصحة
• علاج الجميع بدون تمييز.
• الالتزام بالواقعية الطبية.
• الاستجابة السريعة للبلاغات.
• احترام خصوصية المصابين.
🏛️ قوانين العدل / المحكمة
• احترام القاضي والجلسة.
• الكلام فقط بإذن.
• وجود أدلة قبل الحكم.
• المحامي له حق الدفاع الكامل.
• ممنوع التهديد داخل المحكمة.
👨‍💼 قوانين المواطنين
• الالتزام بالقوانين العامة.
• احترام الجهات الحكومية.
• التصرف بواقعية داخل الرول بلاي.
• ممنوع الفوضى أو التخريب بدون سبب RP.
• المشاركة في التجمعات غير المرخصة ممنوعة.
• الإساءة لرجال الأمن أو تعطيلهم تعتبر جريمة.
• أي سلوك يسبب فوضى أو تهديد للمجتمع عليه عقوبات.
🛠️ قوانين الميكانيكي
• تصليح السيارات بشكل واقعي.
• احترام الزبائن.
• الالتزام بأسعار السيرفر.
